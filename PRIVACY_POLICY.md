# Privacy Policy — Stairway City Explorer

Last updated: November 9, 2026

Stairway City Explorer is a locally running 3D exploration game. The current version does not require an account and does not collect, transmit, sell, or share personal information. It does not include advertising or analytics SDKs.

## Conversations with in-game characters
Text entered in conversations with city residents is processed locally in the game. Replies are scripted. Conversation text is not sent to a server and is not retained after the game is closed.

## Local storage
The game does not store a player profile or conversation history. The web version may cache static game files in the browser so the game can load faster and may work offline after the first visit.

## Third-party services
The mobile app bundles the game code and required libraries. This policy does not cover services provided by the device operating system or the app store from which the app is downloaded.

## Contact
For privacy or support questions, use the project support page:
https://github.com/mmbeno770-collab/stairway-city-explorer-full

The privacy disclosures must be checked again if analytics, ads, accounts, online chat, or other data services are added in a future version.
